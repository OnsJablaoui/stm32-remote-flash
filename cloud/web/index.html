Du code à la carte, en quatre étapes

    
Le programme ne passe jamais directement de votre PC à la carte : il transite par le serveur, et c'est la passerelle qui vient le chercher. Aucun câble, aucun logiciel à installer.

    
    
      
  1. 
        
    Compilez
    
        
    Dans STM32CubeIDE, activez la sortie binaire (Convert to binary file) et compilez. Le fichier .bin se trouve dans le dossier Debug.
    
      
    2. 
      
  2. 
        
    Déposez
    
        
    Envoyez le .bin depuis cette page. Il rejoint la file d'attente du serveur avec son empreinte SHA-256.
    
      
    3. 
      
  3. 
        
    La passerelle programme
    
        
    L'ESP32 télécharge le fichier, contrôle son empreinte, efface la flash, l'écrit puis la relit octet par octet.
    
      
    4. 
      
  4. 
        
    Lisez la sortie
    
        
    La carte redémarre sur votre programme. Tout ce qu'il écrit avec printf s'affiche ici, en direct.

Le banc de test

    
Une carte réelle, branchée en permanence à une passerelle Wi-Fi. Votre programme s'exécute sur ce matériel, pas sur un simulateur.

    

      

        
        
      

      

        

          
            
Carte cibleBlue Pill, STM32F103 (Cortex-M3)

            
PasserelleESP32, connectée en Wi-Fi

            
Liaison série du programmeUSART1, broches A9 (TX) et A10 (RX), 115 200 bauds, 8N1

            
ProgrammationBootloader intégré de ST, sans sonde ST-LINK

            
VérificationsEmpreinte SHA-256 du fichier, puis relecture complète de la flash

            
Limites256 Ko par fichier, 30 secondes d'exécution

          
        


        
Pour afficher du texte

        
Activez USART1 en mode Asynchronous dans STM32CubeMX, puis ajoutez cette fonction dans main.c. Vos printf s'afficheront dans le résultat.

        
#include <stdio.h>

int __io_putchar(int ch)
{
    HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, HAL_MAX_DELAY);
    return ch;
}

/* Pour terminer l'exécution sans attendre 30 s : */
printf("FIN\r\n");
